Pre-event checklist

Event layout map
How to use the map 1. Select a location above — the site map loads automatically. 2. Pick a resource type from the toolbar below (e.g. Tent, Stage, Food Truck). 3. Point resources (Lighting, Water Monster, Generator, etc.) — click once on the map to drop a pin. 4. Area resources (Tent, Stage, Tables) — click and drag to draw the footprint. You can draw over existing areas. 5. Food Truck — click once to place at a standard size. 6. Move a rectangle — drag the ✥ handle in the bottom-left corner. 7. Resize a rectangle — drag the ⤡ handle in the bottom-right corner. 8. Rotate a rectangle — drag the ↻ handle in the top-right corner to align with the map angle. 9. Add a note or remove — double-click any resource to add a note (e.g. "2 trucks side by side") or remove it. 10. Undo — click ↩ Undo to remove the last placed resource. Overlapping areas are shown transparently so you can see what's underneath — e.g. chairs and a stage inside a tent. To add a custom resource type, type a label in the custom field and click + Add.
